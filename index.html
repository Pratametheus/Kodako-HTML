Apa ini?

Kodako HTML adalah alat belajar membuat halaman web dengan blok, mirip Scratch. Susun blok Struktur, Konten, dan Gaya, lalu langsung lihat hasilnya sebagai halaman web sungguhan — lengkap dengan panel "Lihat Kode" yang menunjukkan HTML aslinya.

Cara pakai

  1. 1📂 Buka editor dan buat project baru.
  2. 2🧩 Seret blok dari palet, susun jadi program.
  3. 3▶️ Klik Jalankan untuk melihat pratinjau, lalu simpan project-mu.

Untuk Guru

Kodako HTML adalah alat editor blok untuk mengajar HTML dasar — bisa langsung dipakai di kelas, gratis, dan tanpa internet. Panduan singkat cara pakainya ada di tombol "Bantuan" di dalam editor.
